# 《南开管理评论》投稿格式模板

> 来源：《南开管理评论》官网投稿指南：https://nbr.nankai.edu.cn/nkglpl/site/menu/20250409113634001
> 投稿系统：https://nbr.nankai.edu.cn（注册作者账户在线投稿）

## 硬性要求

- 在线投稿（官网注册）；切勿一稿多投；同一稿件仅投一次，勿短时间密集投稿
- 稿件全文采用 **Word 文档格式**
- **匿名铁律（比一般期刊更严）**：审稿全过程中，投稿正文、后续修订版本及修改说明（含修改说明附件）等所有呈外审材料中，**均禁止出现任何形式的个人信息**——中英文姓名、基金，或其他可能暴露个人信息的环节、暗示，**如 Word 软件用户名、文件名等**
- 基金项目：投稿正文中**切勿出现基金名称**（在投稿系统注册后选择基金名称并填写项目编号）；资助基金项目不超过 3 个

## 投稿附件（除正文外另提交）

1. **投稿信**（仅供编辑部内部参考）：须明确指出所投文章的主要研究方法、论文主要创新点、论文不足及局限
2. **作者学术简历**：作者姓名、单位、职务、职称、研究方向、发表论文、主持科研项目等

## 字数

- 稿件正文篇幅以 **1.5 万—2 万字**为宜

## 论文结构（正文格式原文）

```
中文标题（不超过20个字）→ 摘要 → 关键词（3-6个）→ 引言（正文一级标题）
→ 一、内容 [1.（正文二级标题），（1）（正文三级标题）]……
→ 结论 → 参考文献[1]…… → 注释①…… → 英文标题 → 英文摘要 → 英文关键词 → 附录
```

- **注意：注释排在参考文献之后**（"参考文献[1]……→注释①……"，非当页脚注）

## 标题编号

- 一级标题：`引言`、`一、`、`二、`……（中文序号体系）
- 二级标题：`1.`、`2.`……
- 三级标题：`（1）`、`（2）`……

## 参考文献（顺序编码制，不用哈佛著录法）

- 限于公开发表文献；**数量一般不超过 60 篇；作者引用自我的参考文献建议不超过 3 个**
- **排列次序按文中出现先后为准**（不用哈佛著录法）
- 正文中引用只写序号 [1]、[2]……
- 书写格式参考本刊已发表论文（官网未给出具体样例）

## 图表

- **图表请使用可编辑形式，不要直接使用图片格式**

## 官网未注明（生成前对照本刊近期发表论文复核）

- 正文字体字号、行距、页边距、页码、摘要字数、图注/表题格式、参考文献具体格式

## 案例研究投稿新要求（案例论文专用）

投稿案例论文时，需单独附一页"**案例研究贡献说明**"（切勿直接复制粘贴正文内容），包括六方面：
1. 核心研究问题：用一句话说明本研究试图回答的科学问题
2. 单案例研究：扼要描述案例故事梗概，务求精彩有趣，**切勿写成企业简介或时间线列表**；多案例研究：说明抽样方法、理由和逻辑；数据分析采用扎根理论或 Gioia 方法的，说明合理性与必要性
3. 用一段通俗、自然语言（避免专业术语）说明所研究案例的独特启发性，管理实践者能学到的最重要的一两个新洞见，具备可操作性和适用性
4. 说明本研究对话的文献领域及细分领域（无需描述研究现状）
5. 用通俗语言明确说明最重要的一两个具体理论贡献（新概念/新规律/对已有理论的新解释），**不能笼统宣称深化已有研究、引入新理论视角或构建新研究框架**
6. 作者团队是否已开发出对应教学案例？是则提交该教学案例作为投稿附件

## 生成时注意

- 投稿版全文匿名（含 Word 文件属性中的用户名、文件名）
- 基金信息不进正文（投稿系统填写）
- 结构顺序：正文 → 结论 → 参考文献 → 注释 → 英文部分 → 附录
- 参考文献 ≤60 篇、自引 ≤3、按出现先后
- 图表用可编辑格式（Excel 图表/矢量，非截图）
- 格式要点随官网更新而更新，生成前复核
