## 新增模板步骤

1. 查期刊官网投稿须知（cn-web-research 技能），提取：字体字号（标题/正文/摘要/注释）、行距、标题层级、表格规范、参考文献格式、图表要求、字数限制、匿名要求
2. 官网不可达 → 用期刊近两年发表论文反推格式（3-5 篇对照），模板内注明"反推，非官网原文"
3. 按 `_通用CSSCI.md` 的结构复制建文件
4. 本 README 登记（期刊名 → 文件 → URL → 日期）

## 维护规则

- 格式要点随官网更新而更新；每次生成投稿版前复核目标期刊模板的关键项
- 反推格式的模板标注来源为论文样例，注明"以官网为准"
