# 《管理科学学报》投稿格式模板

> 来源：《管理科学学报》官网投稿指南：https://jmsc.tju.edu.cn/jmsc/site/menu/20070624153255001
> 补充：《关于新投稿上传匿名文件的通知》（2023-01-15）：https://jmsc.tju.edu.cn/jmsc/news/view/20230116102947001
> 投稿系统：http://jmsc.tju.edu.cn（2012 年起远程投稿，不再接受纸质稿）

## 硬性要求

- 所有稿件通过投稿系统（http://jmsc.tju.edu.cn）注册投稿；不再接受纸质投稿
- **自 2023-01-15 起，投稿须上传匿名稿件**：去除作者、单位、基金资助信息等内容（**包括英文作者、单位等**）
- 上传文稿为 **Word 或 PDF 格式**；图表、公式、符号、上下角标、外文字母印刷体应符合规范
- 稿件未在其它公开发行期刊或正式出版会议论文集上发表过

## 字数

- 全文以**不超过 8000 字**为宜（有价值的综述性论文可放宽到 **12000 字**，包括图表在内）
- 3 千字以内短文不受结构限制

## 论文结构（正文格式原文）

```
（中文）主题 → 作者姓名 → 工作单位 → 摘要 → 关键词（3—8个）
→ 1 引言（正文一级标题）→ 内容（1.1（正文二级标题）…，1.2…）… → 结论
→ 参考文献 → （英文）主题 → 作者姓名 → 工作单位 → 摘要 → 关键词 → 附录
```

- **摘要不超过 300 字**

## 标题编号（数字体系，区别于中文"一、"体系）

- 一级标题：`1`、`2`、`3`……（如"1 引言"）
- 二级标题：`1.1`、`1.2`……
- 其余层级官网未注明 → 对照本刊已发表论文

## 公式与表格

- 文中独立的数学公式按先后顺序**统一编号**
- 表格的编号、题目、各栏应填全，不得省略

## 参考文献（顺序编码制）

- 引证的参考文献限于**公开发表**的；**排列次序按文中出现先后为准**（非字母排序）
- **正文中引用时只写序号 [1]、[2]……**
- 书写格式参考本刊已发表论文（官网未给出具体格式样例）

## 作者信息与基金

- 来稿注明作者真实姓名、工作单位、职务、职称和通讯处
- 论文受省部级以上基金项目支持：注明**基金名称和项目编号**

## 作者简介（本刊编辑要求）

- 每篇论文首页作为**脚注**排版，**总字数不超过 100 字**
- 详实注明：通讯地址、邮政编码、联系电话；可增加研究方向、职务、职称、学历等内容

## 官网未注明（生成前对照本刊近期发表论文复核）

- 正文字体字号、行距、页边距、页码、图注/表题格式、参考文献具体格式

## 生成时注意

- 投稿版**全文匿名**（含英文作者单位）——作者信息另行提交或放首页后删除
- 字数上限 8000 字（此刊是上限不是下限）
- 标题用数字体系（1 / 1.1），不用"一、（一）"
- 参考文献顺序编码制、按出现先后（与字母排序的期刊相反）
- 作者简介：首页脚注 ≤100 字
- 格式要点随官网更新而更新，生成前复核
